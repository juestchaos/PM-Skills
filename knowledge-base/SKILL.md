# Knowledge Base

## Overview

This skill provides access to structured knowledge for product requirements and technical specifications.

## Usage

When writing product documentation, explicitly reference knowledge categories:

- "基于[知识类别]，写需求文档"
- "参考[技术领域]知识，设计功能规格"  
- "使用[基础概念]，制定产品需求"

## Knowledge Categories

### Technical Fundamentals
- Web scraping methodologies
- Data processing patterns  
- API design principles
- Error handling strategies

### Product Patterns
- User requirement templates
- Feature specification formats
- Acceptance criteria standards

### Domain Knowledge
- Government website characteristics
- Real estate data structures
- Regulatory compliance requirements

## Integration

This skill automatically integrates with:

### Priority Sources (置顶，优先加载)
- **MEMORY.md** - 个人化知识和长期记忆
- **product-manager/SKILL.md** - 产品经理最佳实践和方法论
- **ui-ux-pro-max/SKILL.md** - UI/UX 设计规范和设计系统

### Project Knowledge (按修改日期倒排)
- **references/** directory - 项目特定知识库
  - `product/` - 产品需求模板、用户故事、验收标准
  - `tech/` - API 设计、数据库规范、技术架构
  - `domain/` - 领域知识（签到/积分/消息等业务）
  - `best_practices/` - 代码审查、测试规范等最佳实践
